[color=#FFFFFF][u][size=130][b]Features[/b][/size][/u][/color]
• [color=#80FFFF][b]Goldberg Emulator Management[/b][/color][color=#FFFFFF] - Downloads, installs, updates and fixes Goldberg Emulator files for ([url=https://github.com/Detanup01/gbe_fork]Detanup01/gbe_fork[/url] and [url=https://github.com/alex47exe/gse_fork]alex47exe/gse_fork[/url]).[/color]
• [color=#80FFFF][b]Game Lookup[/b][/color][color=#FFFFFF] - Find games using either the App ID or game name.[/color]
• [color=#80FFFF][b]steam_settings folder[/b][/color][color=#FFFFFF] - Automatically create Goldberg configuration files (including achievements, items, and stats).[/color]
• [color=#80FFFF][b]Goldberg launch modes[/b][/color][color=#FFFFFF] - Support all [/color][color=#80FFFF][b]Steamclient[/b][/color][color=#FFFFFF], [/color][color=#80FFFF][b]Steam_api[/b][/color][color=#FFFFFF], [/color][color=#80FFFF][b]Steam.dll[/b][/color][color=#FFFFFF] and [/color][color=#80FFFF][b]ColdClient loader[/b][/color][color=#FFFFFF].[/color]
• [color=#80FFFF][b]Library Management[/b][/color][color=#FFFFFF] - Organize games and configure launch settings.[/color]
• [color=#80FFFF][b]Per-Game Launch Options[/b][/color][color=#FFFFFF] - Customize launch arguments individually for each game.[/color]
• [color=#80FFFF][b]User Profiles[/b][/color][color=#FFFFFF] - Create and switch between profiles (Steam ID and save data only).[/color]
• [color=#80FFFF][b]SteamStub[/b][/color][color=#FFFFFF] - Automatically handled while keeping SCF intact after execution.[/color]

[color=#FFFFFF][u][size=130][b]What's New[/b][/size][/u][/color]
• [color=#80FFFF][b]Missing game dependencies[/b][/color][color=#FFFFFF] - Before launch, checks for common Windows runtimes a game may need (such as Visual C++ or DirectX) and can install them for you.[/color]
• [color=#80FFFF][b]LAN Players[/b][/color][color=#FFFFFF] - Discover other SmartGoldbergEmu users on the local network, chat, mute or block peers, and send game invites with setup info for supported titles.[/color]

[color=#FFFFFF][u][size=130][b]Quick start[/b][/size][/u][/color]
[color=#FFFFFF]
1. Download the [url=https://github.com/delabarra/SmartGoldbergEmu/releases]latest release[/url].
2. Launch SmartGoldbergEmu.exe (allow updates if prompted).
3. Add one or more games to your library.
4. Configure any desired launch options or emulator settings.
5. Start your game directly from SmartGoldbergEmu.
[/color]
